# Zarzamora

Tienda y portfolio de las apps de Joako Zarza: catálogo, fichas estilo Play Store, guía de instalación y un panel para administrar todo sin tocar código.

- **Stack:** Next.js 16, Tailwind CSS 4, Supabase (base de datos, inicio de sesión y archivos).
- **Desarrollo:** `npm install` y `npm run dev`, y después abrí http://localhost:3000.
- **Configuración y publicación:** ver [docs/SETUP.md](docs/SETUP.md).
- **Base de datos:** [supabase/schema.sql](supabase/schema.sql).
- **Maquetas de referencia:** carpetas `stitch_zarzamora_app_portfolio_*`.
